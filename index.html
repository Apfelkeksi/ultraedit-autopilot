UltraEdit Autopilot

YouTube  This app uses YouTube API Services.

UltraEdit Autopilot is a private desktop tool that the owner of the YouTube channels "Would You Rather Duels" and "Who Takes The Map" runs on his own computer. It renders short videos that he creates himself and schedules them for upload to his own YouTube channels using the YouTube Data API v3.

What it does

  • Uploads the owner's own videos as private with a scheduled publish time (videos.insert)
  • Sets title, description, tags and category
  • Adds each video to one of the owner's own playlists (playlists.list, playlists.insert, playlistItems.insert)
  • Reads the connected channel's name to confirm the right channel (channels.list, mine=true)

The tool has exactly one user: the channel owner. It is not offered to the public, it does not access any other person's account or data, and it does not display YouTube content to anyone.
