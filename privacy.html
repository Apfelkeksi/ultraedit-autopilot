Privacy Policy: UltraEdit Autopilot

Last updated: 31 October 2026

Who uses this app

UltraEdit Autopilot is used only by its developer, to manage his own YouTube channels. No other users can sign in.

What data the app accesses

With the owner's consent (Google OAuth), the app uses the YouTube Data API to upload videos, set their title, description, tags and publish time, and add them to playlists on the owner's own channels. It reads the channel name to confirm the right channel is connected.

How data is stored

The OAuth access token is stored only on the owner's own computer. No data is sent to any server other than Google's. No data is sold, shared or used for advertising. No personal data of viewers or other users is collected.

YouTube and Google

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. Access can be revoked at any time at Google security settings.

Deleting data

Revoking access in the Google security settings and deleting the token file on the owner's computer removes all stored data.
