Privacy Policy: UltraEdit Autopilot

Last updated: 31 October 2026

YouTube API Services

UltraEdit Autopilot uses YouTube API Services. By using it you agree to the YouTube Terms of Service. The Google Privacy Policy applies to the data Google processes.

Who uses this app

The app is used only by its developer, to manage his own YouTube channels. No other users can sign in.

What data the app accesses

With the owner's consent (Google OAuth 2.0), the app uses the YouTube Data API to upload videos, set their title, description, tags and publish time, and add them to playlists on the owner's own channels. It reads the channel name to confirm the right channel is connected. It does not access viewer data, comments, analytics or any other user's information.

How data is used, stored and shared

The OAuth token is stored only on the owner's own computer and is used only to make the API calls listed above. No data is sent to any server other than Google's. No data is sold, shared with third parties or used for advertising. The app does not use cookies or similar technologies.

Deleting data and revoking access

Access can be revoked at any time on the Google security settings page. Revoking access and deleting the token file on the owner's computer removes all data the app has stored. The app keeps no other copies.
